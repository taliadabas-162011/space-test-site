# Space measurement illustrations

The guide uses new, transparent, reference-based photographic illustrations generated with the built-in ImageGen tool. The surrounding application remains a live 3D scene. These assets do not claim flight certification or clinical validation. All pictured readings are examples and never become recorded observations.

Final assets (saved in this directory):

- `oxygen-sequence-v2.png`: open, fit and read a fingertip oximeter. Hardware reference: [Thinkpaul, OxyWatch C20](https://commons.wikimedia.org/wiki/File:OxyWatch_C20_Pulse_Oximeter.png), [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Generated adaptation distributed under CC BY-SA 3.0.
- `pressure-sequence-v2.png`: fit an upper-arm cuff, start, and read both values. Reference: [Beendy234](https://commons.wikimedia.org/wiki/File:Checking_blood_pressure_at_home.jpg), [CC0](https://creativecommons.org/publicdomain/zero/1.0/).
- `temperature-sequence-v3.png`: power, oral placement and reading. Reference: [Nadinviki, digital thermometer](https://commons.wikimedia.org/wiki/File:DIGITAL_THERMOMETER.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Generated adaptation distributed under CC BY-SA 4.0. Earlier packaging and awkward handling drafts are not used.
- `glucose-sequence-v2.png`: strip preparation, blood application and reading. Reference: [mitpatterson2010, Contour USB meter](https://commons.wikimedia.org/wiki/File:Bayer_Contour_USB_Glucose_Meter.jpg), [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/). Generated adaptation distributed under CC BY-SA 2.0.
- `glucose-lancing-v4.png`: separate lancing-pen positioning step, using the manufacturer's documented tool construction and corrected to show soft fingertip-pad contact. Earlier nail-contact and far-side-contact images are rejected and not shipped.

The complete prompt set, reference lineage and generated originals are recorded in `generation-prompts.json`. Generation preserved image alpha. No Python image editing or automatic clinical-image validation was used. Visual checks are not expert clinical approval.

- [AHA upper-arm blood pressure measurement](https://www.heart.org/en/health-topics/high-blood-pressure/understanding-blood-pressure-readings/monitoring-your-blood-pressure-at-home)
- [MedlinePlus temperature measurement](https://medlineplus.gov/ency/article/003400.htm)
- [FDA glucose meter use](https://www.fda.gov/medical-devices/home-health-and-consumer-devices/home-healthcare-medical-devices-blood-glucose-meters-getting-most-out-your-meter)
- [FastClix manufacturer instructions](https://www.accu-chek.com/document/accu-chek-fastclix-lancing-device-owners-booklet-english/download?inline=)
- [NASA in-flight mass measurement](https://www.nasa.gov/image-article/astronaut-shannon-walker-works-columbus-laboratory-module/)

Assigned hardware and mission procedures remain the authority for operation, positioning, sampling, sharps handling and interpretation. The mass guide explicitly requires the assigned station's operating procedure rather than inventing its controls. No ordinary gravity scale is shown as an in-flight mass measurement tool.
