
## Install Crew Health as an app

Open the public site in a supported browser while online and let it finish loading once.
On Android, use Chrome's menu and choose **Install app** or **Add to Home screen**. On iPhone or iPad, open the link in Safari, tap **Share**, then **Add to Home Screen**. On a computer, use the browser's install icon or menu when available. The exact labels depend on the browser and operating system.

The installed app uses the same website and keeps its profile and readings on that device. Clearing browser data or switching devices can remove access to those local records. The bundled app shell is cached for offline use after a successful first visit; external research links, browser speech recognition, and device features may require internet, permissions, compatible hardware, or a supported browser. This is an educational demo, not certified medical software.
